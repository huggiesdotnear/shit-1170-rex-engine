# shit-1170-rex-engine

💩 shit-1170 agentic and defi engine for near

see [FORHACKATHON.md](./FORHACKATHON.md) for hackathon

bun/frontend

```sh
bun i
bunx prettier . --write
bun tsc --noEmit
# bun build recursive
bun run build.ts
```

rust/backend

```sh
cargo fmt
cargo check
cargo run
# cargo build
cargo build --release
./target/release/shit-1170-rex-engine
```
